# Job Evaluation Framework

来源：ai-job-search `04-job-evaluation.md`（浓缩）。

## Gates — run before scoring

Eligibility: 若职位要求公民/永居/安全审查而档案不满足 → **FAIL**，不打分、不起草。引用原文。沉默不是许可。

Language: 只检查职位本身的工作语言，不是广告用语种。
- 要求的语言档案里完全没有 → **FAIL**
- 有该语言但级别可能不够（如广告要 fluent，档案是 B1）→ **FLAG**，可打分，必须明示
- 达标或未写级别 → **PASS**

## Scoring (0-100)

1. Technical Skills 30% — 核心要求是否是候选人主技能
2. Experience Match 25% — 按工作内容匹配，不按头衔字面
3. Behavioral / Culture 15%
4. Career Alignment 30% — 是否朝目标走、任务是否耗能
5. Location — PASS / FAIL / FLAG，不加权。必须搬家 → FAIL

## Verdict

加权平均（地点不计入）：
- 75+ Strong Fit
- 60-74 Good Fit
- 45-59 Moderate Fit
- 30-44 Weak Fit
- <30 Poor Fit

输出表：五维分数、Overall、Verdict、优势、缺口、是否建议申请。
FAIL 闸门或 Location FAIL：建议跳过，除非用户坚持。
