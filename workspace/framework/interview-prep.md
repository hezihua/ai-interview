# Interview Prep

来源：ai-job-search `07-interview-prep.md`（浓缩）。

用已提交的 CV / 求职信 / JD 原文准备，不编造未写入档案的经历。

## Pack

1. 公司与面试官：只写能核验的事实
2. 岗位要求 → 档案中的对应证据
3. 6–8 个可能问题，每个配 STAR（Situation / Task / Action / Result）
4. 缺口：诚实桥接（“还不是日常工具，但是 X 的延伸”），禁止虚构项目
5. 候选人应问面试官的 4–6 个问题（职责、成功标准、团队、挑战）

## Roleplay

用户说「模拟面试」时：一次一问，等回答后再点评（结构、具体性、是否越界编造）。
